## **一、GitHub 调研结论**

存在多个「文字→视频+配音」的项目，最契合你需求的是 **Pixelle-Video**（AIDC-AI 出品，Apache-2.0，中文项目）：输入主题或固定文案 → 自动配图 + Edge-TTS 语音解说 + BGM + 合成竖屏/横屏视频，自带 Web 界面。我已下载到：  
`C:\Users\Administrator\WorkBuddy\视频创建...`

## **二、我做的关键改造（让它不需要任何付费 Key 也能出片）**

原版强依赖 ComfyUI/RunningHub（要 GPU 或云 Key）才能生图、要配 LLM 才能写稿。我做了这些让它可以「离线可用」：

- 新增 `local_image.py`：纯 Pillow 生成本地渐变配图（无需 GPU/Key）。
- 新增 `pil_frame.py`：Chromium 不可用时用 Pillow 合成字幕帧，保证一定能出片。
- `schema.py`：本地 TTS + 本地生图时无需 LLM 也视为配置有效。
- `standard.py`：固定文案模式下无 LLM 时用首行当标题、跳过 LLM 提示词生成。
- 修复了 `image.py` 本地生图分支的一个 `NameError`。
- 内置 `ffmpeg`（v9.0.2，`ffmpeg/bin/ffmpeg.exe`），并写了 `get_ffmpeg.py`/`extract_ffmpeg.py`，缺 ffmpeg 时启动脚本会自动下载。

## **三、已实测跑通（不是纸上谈兵）**

用示例文案「阅读的力量」完整跑了一遍：4 个分镜 → Edge-TTS 配音 → 本地配图 → 帧合成（中文标题/字幕正常）→ ffmpeg 生成并拼接 → **成片 15.83 秒、1080×1920、h264+aac、0.46MB**。右侧已展示成片与截帧。Web 界面也验证可正常启动（[http://localhost:8501](http://localhost:8501)）。

## **四、怎么用**

进入 `Pixelle-Video` 目录：

- **命令行演示（无需任何 Key）**​：双击 `launch_demo.bat` → 自动出片到 `output\`。
- **网页界面**：双击 `launch_web.bat`，浏览器打开 [http://localhost:8501](http://localhost:8501) ，在里面输入文字生成。

要生成自己的内容，编辑 `demo_offline.py` 里的 `text`（每行一句解说词）；或在 Web 界面直接输入。

## **五、想升级成「AI 自动写稿 / AI 精美配图」**

编辑 `config.yaml`：

- 填 `llm.api_key / base_url / model`（如通义千问、DeepSeek）→ 用「主题」自动写分镜稿。
- 把 `comfyui.image.backend` 改为 `comfyui` 并填 `runninghub_api_key` → 用 AI 生成真实插画配图（本地模式则是渐变背景）。

说明：本机网络正常时，Edge-TTS 配音、ffmpeg 合成、Web 界面均可直接使用；离线兜底的配图是「按文案色调生成的渐变背景」，若需要写实画面请按第五节接入 AI 生图。

**以后的启动方式**（已加固，不会再出现跳端口问题）：

- 双击 `launch_web.bat` → 自动在 8501 启动并打开网页；
- 命令行演示（无需界面）：双击 `launch_demo.bat` 直接出片到 `output\`。
